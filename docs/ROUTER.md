## 📋 Очередь задач: Particle Celebration VFX & Polish

### 🔵 FX-2 — GLSL Curl Noise & Вихревая турбулентность · 🔵 15 мин
- **🎯 Цель:** Устранить механическое прямолинейное движение частиц. Добавить органический вихревой закрут (curl/simplex noise) в вершинный шейдер перед фиксацией в глиф.
- **📂 Файлы:** `src/lib/particle-celebration.ts`
- **📏 Правила:** 
  - Никаких внешних библиотек шума. Использовать компактную GLSL-функцию 2D/3D шума (~10-15 строк в строковом литерале `VERT`).
  - Вектор шума масштабируется от максимума на старте (`uProgress < 0.5`) до 0 при сборке (`uProgress > 0.8`), чтобы символ оставался идеально чётким и читаемым.
  - Zero-overhead: не добавлять новых uniform, если можно вычислить из `pos` и `uProgress`.
- **✅ Done:** Частицы закручиваются в мягкий спиралевидный вихрь перед сборкой; в точке `uProgress = 0.8` форма символа на 100% стабильна и различима.
- **🔍 Verify:** `npm run gate` + визуальная проверка в превью/браузере.

### 🟡 FX-3 — Аддитивное свечение (Additive Blending / Glow) · 🟡 10 мин
- **🎯 Цель:** Сделать кульминацию Goal Reached и Personal Best неоново-яркой без тяжелых шейдеров размытия/Bloom.
- **📂 Файлы:** `src/lib/particle-celebration.ts`
- **📏 Правила:**
  - Добавить опцию `blendMode?: 'normal' | 'additive'` в `CelebrationOptions`.
  - Для `goalReached` и `personalBest` выставлять `gl.blendFunc(gl.SRC_ALPHA, gl.ONE)`.
  - Для `milestone` (50%, 75%) сохранять мягкий `gl.ONE_MINUS_SRC_ALPHA`, чтобы промежуточные майлстоуны не слепили.
  - Не ломать прозрачность канваса над UI: очистка `gl.clearColor(0, 0, 0, 0)`.
- **✅ Done:** На пересечениях частиц в символах `€` и `★` возникает яркое ядро свечения; канвас остаётся прозрачным над карточками HomeScreen.
- **🔍 Verify:** `npm run gate` + переключение темы (Dark/Indigo/Light).

### 🔵 FX-4 — Кинетическая дисперсия с физикой разлёта (Dispersion Burst) · 🔵 15 мин
- **🎯 Цель:** Заменить статичное угасание по прозрачности на динамичный импульсный разлёт или гравитационное оседание искр.
- **📂 Файлы:** `src/lib/particle-celebration.ts`
- **📏 Правила:**
  - В вершинном шейдере на фазе `uProgress > 0.75` добавить вектор смещения: радиальный импульс от центра наружу `normalize(pos) * burstStrength` либо гравитационный спад `vec2(0.0, -gravity * t2)`.
  - Время жизни частиц: к `uProgress = 1.0` альфа падает до 0, разлёт не должен вылетать за границы канваса резкими артефактами.
- **✅ Done:** Символ держится собранным 0.3с, затем эффектно взрывается мелкими искрами и плавно растворяется перед dispose.
- **🔍 Verify:** `npm run gate` + отсутствие скачков кадров в Chrome DevTools Performance.

### 🟢 FX-5 — Тактильная синхронизация (Haptic Feedback Pulse) · 🟢 10 мин

- **📂 Файлы:** `src/hooks/useCelebration.ts`, `src/components/HomeScreen.tsx`
- **📏 Правила:**
  - Вызывать `navigator.vibrate` строго с проверкой:
    1. Поддержка в браузере (`'vibrate' in navigator`).
    2. Уважение настройки `settings.hapticEnabled` (из `AppSettings`).
    3. Не вибрировать в режиме энергосбережения (`isPowerSaveMode`).
  - Паттерн: короткий акцентный щелчок `[15, 30, 20]` для Goal Reached и лёгкий одиночный `[10]` для 50%/75%.
  - Запуск таймером ровно на момент схождения частиц (`t = duration * 0.55`).
- **✅ Done:** При закрытии цели телефон издаёт тактильный щелчок в момент фиксации глифа; при отключённом haptic в Settings — полная тишина.
